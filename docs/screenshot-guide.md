# Screenshot Guide

Screenshots make the portfolio more credible because they show the investigation workflow visually.

## Recommended Screenshots

### 1. Sentinel Incident

Capture:

- Incident title
- Severity
- Entities
- Timeline

### 2. Failed Login Query

Show:

- User
- IP
- Failure count
- First seen
- Last seen

### 3. Success After Failures

Show:

- Failure count
- Success timestamp
- IP
- Application

### 4. Geographic Anomaly

Show:

- Previous country
- Current country
- Time difference

### 5. PowerShell

Show:

- Device
- Account
- Command line
- Timestamp

### 6. Device Timeline

If using Defender, capture the relevant process event in context.

## Redaction

Before committing screenshots to GitHub, remove or blur:

- Real names
- Real email addresses
- Tenant IDs
- Subscription IDs
- Real device IDs
- Customer information
- Confidential IP addresses
- Access tokens
- Case numbers
